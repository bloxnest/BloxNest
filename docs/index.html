How to start

BloxNest is a single executable. Save it somewhere you want to keep it, then run it when you need multiple windows.

  1. Download the file from GitHub

    The download button links directly to BloxNest.exe in the latest GitHub release. You can also read the release information before downloading.

  2. Read the warning, then decide whether to run it

    There’s no setup wizard. Open BloxNest.exe if you choose to proceed after reading the first-run note.

  3. Choose a count and open Roblox

    Finish anything in your current Roblox windows first: the opening button closes them before starting the selected number.

    Use a different Roblox account in each window. Using the same account twice kicks you out of one session. Start with a few windows—each one uses memory.

“Windows protected your PC”

BloxNest isn’t code-signed yet. Windows may show this warning on the first run.

Check that the file came from the linked GitHub releases. The source code is public, but that alone doesn’t prove a downloaded executable is safe or matches the source.

If you’ve checked the release and choose to proceed, select “More info”, then “Run anyway”, if Windows offers those options.

If you’re unsure, don’t run it. You don’t need to disable Windows security to use this page.

What you can change

The Options screen controls timing, Roblox updates, and what happens when you close BloxNest. Your choices are saved for next time.

Time between windows
Choose 3, 5, or 8 seconds. A longer delay gives a slower PC more time to open each window.
Update Roblox before opening
When enabled, BloxNest checks Roblox’s latest version. If an update is needed, it checks that your existing Roblox updater is signed by Roblox Corporation before running it.
Roblox update alerts
When enabled, BloxNest checks every 30 minutes while running and tells you when Roblox updates.
Keep running in hidden icons
Closing the BloxNest window can leave it running in the system tray. Right-click its icon to open or quit. Launching BloxNest again brings back the running app.

Privacy

BloxNest doesn’t collect, store, or send your Roblox account details, passwords, or cookies. It has no analytics or tracking.

It does contact Roblox for version checks. That is separate from collecting account information.

Version checks go to Roblox
BloxNest only contacts Roblox’s own server to check the newest version. It doesn’t download Roblox installers or update packages itself. When needed and enabled, it runs the Roblox updater already on your PC after checking its signature.
No injection or direct game-file changes
BloxNest opens Roblox and stops its “only one window” check from closing the extra windows. BloxNest itself doesn’t modify Roblox’s files or inject code into the game. Roblox’s updater handles any game updates.
Preferences are saved locally
BloxNest saves your options in your AppData folder. That preferences file is the only file BloxNest itself saves.

Questions before downloading

Can I get banned?

BloxNest doesn’t modify Roblox or inject anything, but it isn’t made or approved by Roblox. Nobody can promise anything. Use it at your own risk.

Can I use the same account in two windows?

No. Using the same Roblox account twice kicks you out of one session. Use a different account in each window.

How many windows should I open?

You can choose 1–5 with a click or enter a number up to 20. That is the app’s limit, not a promise that your PC can run 20 comfortably. Every Roblox window uses memory. Start small.

Why does Windows show a warning?

BloxNest isn’t code-signed yet, so Windows may show “Windows protected your PC.” Read the first-run note and check the release information before deciding whether to run it.

Does BloxNest download Roblox updates?

It retrieves version information, not Roblox update packages. With updating before opening enabled, it runs the Roblox updater already on your PC when needed, after checking that it’s signed by Roblox Corporation. The Roblox updater handles the download.

I closed BloxNest. Why is it still running?

With “keep running in hidden icons” enabled, closing the window leaves BloxNest in the system tray. Right-click its icon to open or quit. Launching BloxNest again brings back the running app rather than starting another copy.

Is it free, and what does it run on?

Yes. BloxNest is free and open-source under the MIT licence, made by xRed1. It runs on Windows 10 and 11. The executable is about 160 KB and has no installer. It does not run on phones.
